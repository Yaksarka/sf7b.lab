# Материалы вне репозитория

Сборка и core tests используют только этот checkout, JDK/SDK и публичные зависимости. Приватные исследования не нужны для обычной сборки.

При переносе исключены: ключи/пароли, signing, личные данные, телефонные backup и проекты, старые .git и chat backups, APK оригиналов, DEX/smali/декомпиляция/извлечённые shaders/resources, сырые REA Evidence/XML/screenshots/runtime exports, большие извлечённые registry/schema/catalog JSON и локальные скрипты исследования с зависимостью от закрытых snapshots. Собственные Android/core исходники включены полностью, за исключением результатов сборки.

Исходные папки и private архивы не удалены. Сохранённые здесь отчёты — текстовые сводки с указанием ограничений, а не полная доказательная база. Ссылки на отсутствующие файлы при переносе превращены в текст; это не означает, что соответствующая проверка выполнена заново. Старые SHA относятся к исходным артефактам; санитарная обработка отчётов меняет их собственные bytes.

Не публикуй закрытые материалы автоматически ради продолжения исследования. Если конкретная будущая задача требует Evidence, сначала установи наличие разрешённого материала и прав на его перенос; при отсутствии честно обозначь ограничение. Отдельный перенос исходного ключа: [SIGNING](SIGNING.md).
