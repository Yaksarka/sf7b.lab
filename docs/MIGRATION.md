## Другой аккаунт и ИИ-сервисы

Владелец может выдать конкретному второму аккаунту доступ через GitHub Settings → Collaborators; приглашение нужно принять вторым аккаунтом. Логин второго аккаунта не предоставлен, приглашения при переносе не отправлялись. Если требуется другое владение целиком, используйте штатный transfer ownership после отдельного выбора получателя.

Каждый ИИ-сервис подключается отдельно под нужным аккаунтом: выберите этот private-репозиторий в GitHub App/OAuth-интеграции и выдайте минимально достаточный доступ. Приватный доступ и возможность push зависят от сервиса и тарифа; подключение одного сервиса не авторизует остальные. Для сервиса без доступа к private repos используйте локальный checkout либо очищенный экспорт, сохраняя приватность проекта.

GitHub App внутри текущего ИИ может требовать выбора нового репозитория в настройках установки; права Git CLI и GitHub App независимы. Доступ второго аккаунта и внешних ИИ-сервисов при переносе не проверялся.

GitHub Actions запускается вручную, без изменений оплаты. Его Linux-команды подготовлены, но локальная Windows-сборка сама по себе не доказывает успешный Linux workflow.
