# Подпись обновлений

Ключ не хранится в GitHub и не копировался в новый репозиторий. На исходном компьютере он исторически находился в signing/sf7b-debug.keystore рабочей папки и отдельном signing backup. Его bytes и пароль не включены в документы или отчёт переноса. Факт наличия ключа не является новой проверкой соответствия установленному APK.

Для переноса скопируйте существующий ключ и сведения о нём отдельно в защищённое хранилище, затем на новый компьютер вне checkout. Не отправляйте ключ или пароль в ИИ-чат. Задайте переменные только локально:

- SF7B_KEYSTORE_PATH — абсолютный путь к существующему внешнему keystore.
- SF7B_STORE_PASSWORD, SF7B_KEY_ALIAS, SF7B_KEY_PASSWORD — значения из защищённой записи владельца.

Сборка для обновления установленной версии должна дополнительно требовать ключ:

~~~bash
./gradlew -Psf7bRequireRetainedKey=true :app:assembleDebug
~~~

Без ключа обычная debug-сборка допустима для отдельной тестовой среды. Не пытайтесь исправить несовпадение подписи удалением приложения: это может уничтожить внутренние проекты. До установки проверьте сертификат APK средствами Android SDK и сравните с подтверждённым сертификатом прежней сборки; перенос не выполняет такую проверку на телефоне.
