# Наблюдения UI OneLab и соответствие sf7b.lab

Состояние 13.11.2026: наблюдения оригинала получены, интерфейс sf7b ещё не приведён к ним полностью. Эталон — установленный OneLab 1.5.3/code138 на A51 Android13, 1080×2400. Advanced уже был выбран. Исследуется только собственный synthetic grid; перед его загрузкой original показывал пустой START. Пользовательская работа не заменялась.

## Наблюдённые состояния

- Начальный START/Load/Generator: экран (материал отсутствует в этой копии).
- Обычный редактор: белая верхняя панель с Undo, Redo, Bookmark, Save, Menu справа; большой checker viewport; внизу слева полупрозрачная плашка текущего узла с eye/edit.
- Постоянная нижняя панель со скруглённым верхом, ручкой, down/up. Source Image / Random Mode рядом, далее Discovery и категории Geometry/Glitch; бирюзовые карточки с подписью. Она не закрывает всё модальным sheet.
- Собственный fixture загружен (материал отсутствует в этой копии) обычным PhotoPicker, а не SEND. Source Image открывает редактирование исходного узла.
- Source edit (материал отсутствует в этой копии): Cancel слева, Bookmark/Save/Repeat/Confirm справа; нижние квадратные группы Modifiers/Image, далее Effects. Под ними чёрная полоса с крупными миниатюрами узлов/эффектов.
- Glitch открывает подкатегории Presets/Glitch/Break/Streak/Retro, отдельные быстрые Adjust/Rotate/Crop/Eraser/Basics.
- Break / Disintegrate (материал отсутствует в этой копии): горизонтальные карточки эффектов внизу; групповые кнопки Mode/Length/Shadows/Transform, отдельный Background. Эффект виден до подтверждения. Горизонтальная прокрутка меняет выбранный эффект.
- Dichotomic Break показывает **Unlock this effect**. Доступность runtime-проверки всего каталога на данном установленном OneLab не подтверждена. Покупок/изменений лицензии не делалось. Сведения об остальных блокировках дополняются по мере наблюдений.

XML, действия и guards находятся в `research/runtime/ui-steps`, REA Evidence — `research/raw/onelab-a51-*.json`. Исходные значки, шрифты, иллюстрации и изображения карточек Ilixa не переносятся в APK. Нужны собственные изображения sf7b, повторяющие назначение и компоновку элементов.

Параметрические sliders/numeric input, tree/branches, экспорт/форматы, темы, клавиатуру и дополнительные категории. Затем реализовать и снять соответствующие экраны sf7b; наличие похожих цветов само по себе не доказывает сходство взаимодействий.
