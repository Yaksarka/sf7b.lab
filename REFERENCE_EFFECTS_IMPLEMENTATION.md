# Самостоятельные реализации исследованных механизмов v2

Источник — статические наблюдения REA по предоставленным APK, собранные в `research/`. Исходный код и шейдеры оригиналов не включены в реализацию sf7b.lab. Пары runtime-экспортов оригинал → sf7b.lab пока не подтверждены; попиксельное совпадение, точные исходные UI-диапазоны и тождество seed-рисунка не заявляются.

## Механизмы

- Random Pixelate v2: дерево прямоугольных разрезов, сначала Y, далее чередование осей; regularity влияет на выбор длинной оси и при значениях выше 50 приближает разрез к середине. Bias ослабевает с глубиной. При intensity=0 берётся цвет центра ячейки; при ненулевом значении положение относительно центра умножается на 1.01^intensity. Это существенное особое значение нуля, наблюдавшееся статически, а не обычный линейный регулятор силы. Есть границы ячеек и необязательный выбор ближайшего RGBA-цвета палитры.
- Patchwork Break v2: повторяемые прямоугольные разрезы и преобразование координат относительно центра каждой найденной ячейки. Поддержаны наблюдённые семейства scale, fixed-pattern scale, сдвиги по осям/выбранной оси, обратный scale, сдвиг относительно размеров ячейки и поворот. Signed-square intensity управляет преобразованием. Для режимов 1/8/9 базовое дерево сохраняется между повторами; остальные используют следующий seed. Это собственная интерпретация установленных статических механизмов, требующая runtime-сверки.
- Low Freq Banding v2: ColorPickAngular. В преобразованной прямоугольной сетке строятся лучи, для каждого берётся пересечение с границей ячейки, из полученных образцов выбирается цвет с минимальным RGBA-расстоянием до исходного пикселя. Это не генератор синусоидальных полос. Поддержан необязательный второй вход: сравнение идёт с исходным цветом первого входа, образцы берутся из второго, либо из первого, если второго нет. Варианты Glitch Lab/One Lab различают наблюдённый угловой охват 2π/π; дополнительные различия оригиналов ещё не подтверждены.

Реализация трёх механизмов: `core/.../ReferenceEffects.kt`. Вызов возвращает сырую плоскость эффекта; общие mix, mask, enabled и граф применяет Renderer. Разделение выполняется в координатах исходного документа и не зависит от tile size. Расчёт прерываемый по строкам. Внутренний pixel-интерфейс использует примитивы Float/Int без обязательной упаковки объектов на каждый пиксель.

Bloom и Multi Distort v2 интегрируются отдельно в Renderer на основе фактов исследования. Схемы всех пяти v2 находятся в Catalog; параметры версии 1 сохранены отдельно. Новые узлы/встроенные наборы используют текущую версию, старые сохранённые работы — свою версию.

## Собственные проектные решения и ограничения

- PRNG sf7b.lab детерминирован, но не повторяет оригинальный генератор. Совпадение одинаковых численных seed между приложениями не гарантируется.
- Глубина 0…12, repeat count 1…16 и остальные численные пределы/defaults v2 — рабочие диапазоны sf7b.lab. Точные пределы исходного интерфейса ещё не установлены. Названия режимов v2 — собственные понятные подписи, не подтверждённые строки оригинала.
- Разрезы ограничены от вырожденных ячеек; source sampling на краях использует clamp. Эта политика края ещё не сверена с оригиналами.
- Точная связь исходного modelTransform/scale/origin с глубиной разрезов ещё не выведена. Depth и split bias интерфейса sf7b.lab нельзя считать доказанным соответствием исходным ползункам.
- Варианты полного исходного locus и дополнительные преобразования One Lab требуют дальнейшей проверки. Второй вход хранится в графе и переносится с проектом; это не отдельный внешний файл по абсолютному пути.
- Patchwork и Random Pixelate используют первый цвет палитры как цвет границы; alpha этого цвета управляет RGB-наложением с сохранением alpha источника. Опциональная palette quantization Random Pixelate использует RGBA-расстояние.
- Полный каталог оригиналов не считается реализованным на основании этих пяти эффектов.

## Проверки

ReferenceEffectsTest проверяет центр единой ячейки Pixelate, seed/сериализацию/независимость от tile size, identity Patchwork при нулевой интенсивности, изменение от масштаба, аналитический выбор граничного цвета LowFreq, RGBA-выбор из второго источника и перенос второго входа, разделение legacy/current схем и отмену. Это тесты свойств собственной реализации, а не доказательство runtime parity с оригиналом. Фактические результаты запуска публикуются в общем TEST_REPORT.md.

## Дополнительная ограниченная группа Color

`ReferenceColorEffects.kt` реализует четыре новых стабильных ID с первой версией алгоритма 1: color_swap (Color Swap), lum_select (Select by Luminance), channel_multiplier (Channel Multiplier), ink (Ink). Механизмы выведены из документированных One Lab DEX-наблюдений в research/NEXT_COLOR_BEHAVIOR.md; это не перенос шейдерного кода. Названия UI, численные пределы и defaults sf7b.lab не выдаются за проверенные оригинальные настройки.

Color Swap использует первые два цвета палитры как colorIn/colorOut, расстояние RGB с alpha-весом и смешивание прямых RGBA-значений (включая изменение alpha). Lum Select умножает alpha на gate яркости, оставляя RGB. Нулевая tolerance получает определённый exact-match режим вместо NaN. Общая яркость этих операторов использует наблюдённые 0.2989/0.587/0.114, а не коэффициенты существующей общей коррекции.

Channel Multiplier последовательно применяет RGB gains, wrap/fold/clamp, HSL gains, hue в градусах modulo360 и intensity. Alpha сохраняется. Нейтральный clamp-default — собственное безопасное решение; wrap действительно переводит чистый 1 в 0 и не подменяется clamp. Ink соответствует наблюдённому порогу/smoothstep и по умолчанию делает результат opaque. Отдельный явно показанный параметр Keep source alpha является дополнением sf7b.lab.

ReferenceColorEffectsTest проверяет выбранные/далёкие цвета, alpha и прямое RGBA-смешивание, luma-коэффициенты, tolerance0, Ink opaque/optional alpha, нейтральные gains, wrap/fold/hue, отмену и premultiplied-инварианты. Эти восемь тестов не являются runtime-сверкой оригинала.
