# Образцы для проверки приоритетных эффектов

Нужен один общий набор материалов. Без него нельзя подтвердить совпадение с One Lab или Glitch Lab; собственные алгоритмы в приложении уже работают.

Для каждого из пяти эффектов — **Patchwork Break, Low Freq Banding, Multi Distort, Random Pixelate, Bloom** — предоставьте:

1. Название приложения, точную версию и редакцию (например, Glitch Lab, версия из экрана сведений).
2. Исходный файл без промежуточного пересохранения. Можно использовать один и тот же исходник для всех пяти эффектов.
3. Результат PNG при умеренных и при сильных настройках. Сохраните исходный размер, укажите режим экспорта приложения.
4. Снимки всех страниц параметров для каждого результата, включая seed, случайный вариант, смешивание, целевые диапазоны, дополнительные меню.
5. По возможности — повтор с теми же настройками и seed, а также результат на прозрачном PNG. Это покажет повторяемость, поведение границ и альфа-канала.

Предпочтительно взять три исходника: фотографию, рисунок с контрастными краями и градиент с прозрачностью. Если возможно только несколько файлов, начните с одной фотографии и прозрачного PNG. Не присылайте только обработанные картинки без исходников и значений.

Рекомендуемые имена: `original_photo.png`, `original_alpha.png`, `glitchlab_VERSION_patchwork_moderate.png`, `glitchlab_VERSION_patchwork_settings_01.png` и аналогично для остальных эффектов.

Сначала сравниваются исходные размеры, ориентация и прозрачность; затем композиция, структура случайного рисунка, масштаб, края и несколько настроек. Название эффекта само по себе не является доказательством формулы или идентичности между приложениями.
