# Производительность sf7b.lab

Работа продолжается. Цели SPEC не достигнуты для всех операций. Успех сборки и скорость на Windows не означают скорость Galaxy A51.

## Измерение Galaxy A51, candidate4, 13.11.2026

SM-A515F, Android 13/API33; debug APK 0.2.0, Android instrumentation. Собственный PNG sRGB 2000×2000, предпросмотр 1024×1024. Три последовательных прогона каждого сочетания; новый SurfacePool и AndroidSources, общий decode-cache. Это не три независимых холодных запуска приложения. Original OneLab оставался foreground; температура/профиль CPU не контролировались. Настройки питания/сети не менялись.

`DevicePerformanceTest.measureControlledFourMegapixelDocument`, журнал `native-a51-candidate4-performance.log`, OK(1), 205.568 с. Исходные строки: CSV (материал отсутствует в этой копии), summary (материал отсутствует в этой копии).

| Операция | CPU, медиана мс | GPU, медиана мс |
|---|---:|---:|
| Без эффектов | 26 | 914 |
| Adjustment, ненейтральный | 3565 | 874 |
| Adjust → Invert → RGB split → Curves → Posterize | 13628 | 1142 |
| Bloom, algorithmVersion2 | 2668 | 1112 |
| Multi Distort, algorithmVersion2 | 28525 | не поддержан |

Время преобразования готовой плоскости в Bitmap измерялось отдельно: медианы 51–70 мс. Полный CPU-расчёт пяти цветовых эффектов и запись PNG 2000×2000 заняли **38221 мс**, один прогон. Предпросмотр не использовался для полноразмерного результата.

Первый/следующие прогоны отличаются: identity CPU 450/26/21 мс, GPU 2845/846/914 мс. Поэтому приложение обходит GPU для документа без активных эффектов. Для пяти цветовых эффектов GPU быстрее CPU этой же новой реализации примерно в 11.9 раза; это не сравнение со старым APK или оригиналом OneLab.

Интервал render включает создание pool, загрузку рабочего источника, EGL при GPU и вычисление графа. Bitmap-конверсия измерена отдельно. Системный picker, Compose, autosave, получение URI, очистка scratch после закрытия pool и пользовательская реакция исключены. `heap_bytes` — выборка Java+native allocations в конце итерации, **не** максимум, PSS или GPU memory. End-to-end UI latency и пик памяти ещё требуют отдельных проверок.

## Последующие изменения

Повтор того же controlled benchmark candidate5 завершился OK(1), 173.529 с: CSV (материал отсутствует в этой копии), summary (материал отсутствует в этой копии). MultiDistort median **18767 мс**, прежнее значение 28525 мс; остальные CPU/GPU интервалы практически прежние. Полный CPU PNG 38446 мс. Батарея charging69%, температура 25.7→25.8°C; это не контроль всех факторов устройства.

Native candidate6b проверил цепочку MultiDistort→Threshold на том же размере: первый render+cache store 22244 мс; изменение только последнего threshold **1316 мс с кэшем / 20092 мс без кэша**. GPU не участвовал. Результаты cached/cold побайтно совпали, чтение image source при попадании отсутствовало. Один запуск каждого, не медиана и не UI latency. Отчёт (материал отсутствует в этой копии).

Полноразмерная 2000×2000 проверка GPU цепочки Adjust→Invert→RGB split→Curves→Posterize на candidate6b **не прошла**, максимальная ошибка premultiplied канала 64 при допуске3. Поэтому включение GPU-экспорта отложено; исправления порядка квантования/интерполяции и новые prefix regression checks проверяются в следующем кандидате. Положительные маленькие тесты не покрывали этот случай.

- Кэш результатов CPU-узлов ограничен 192 MiB; decode-cache — 384 MiB. Это дисковые бюджеты, не обещание такого потребления RAM. Scratch-pool preview ограничен 48 MiB и вытесняет старые плоскости на диск.
- Ключ CPU-кэша включает структуру входов, версии эффектов/ресурсов, seed, маски, разрешение и проект. Попадание проверяется до вычисления входов. Семь JVM-контрактов прошли; новая A51-метрика ещё собирается.
- MultiDistort отбрасывает окружности, не пересекающие ячейку, и сохраняет список кандидатов. Последующая candidate7 оптимизация кэширует исходные hash-значения lattice в пределах8MiB; для малых footprints прямой расчёт сохраняется. 43884 координаты,12 наборов/аспектов до/после обеих оптимизаций совпали по SHA-256. Это сохранение собственной версии алгоритма, не совпадение с оригиналом. A51-скорость candidate7 ещё не измерена.
- Полный GPU-экспорт пока не подключён. Неподдержанные ветвления/слои/маски/алгоритмы используют CPU. Для тяжёлых цепочек цели 1–3 с preview и около 10 с export остаются открытыми.
