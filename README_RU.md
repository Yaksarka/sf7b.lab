# sf7b.lab — инструкция

Это нативный редактор статических изображений для Android 8.0 и новее. Все инструменты работают на устройстве. В APK нет разрешения INTERNET, рекламы, покупок, водяных знаков и загрузки шрифтов из сети.

Статус проверки и ограничения смотрите в TEST_REPORT.md. Сходство пяти приоритетных эффектов с конкретной версией Ilixa пока не подтверждено. Скорость на Samsung Galaxy A51 требует измерения на телефоне.

## Установить на телефон

1. Возьмите файл `artifacts\sf7b-lab-debug.apk` из этой папки.
2. Подключите телефон к компьютеру по USB, выберите на телефоне передачу файлов и скопируйте APK в «Download» / «Загрузки».
3. Откройте на телефоне «Мои файлы» → «Загрузки» и нажмите APK.
4. Если Android запросит разрешение устанавливать приложения через «Мои файлы», разрешите установку для этого источника и вернитесь к APK.
5. Нажмите «Установить». На экране появится приложение **sf7b.lab**.
6. Для первой проверки отключите Wi-Fi и мобильные данные до первого открытия приложения. Открывайте и сохраняйте файлы в памяти телефона.

Приложению не нужны аккаунт, API-ключ и доступ ко всей галерее. Оно получает только выбранные вами файлы через системное окно Android.

## Первая работа

1. Нажмите «Открыть изображение». Поддерживаются JPEG, PNG и статический WebP. Ориентация EXIF учитывается.
2. Нажмите «Эффекты», найдите нужный эффект по русскому или английскому названию и откройте его.
3. Измените ползунки. Нажмите числовое значение, чтобы ввести число точно. Кнопка ↺ сбрасывает отдельный параметр.
4. «Применить» сохраняет действие. «Отмена» возвращает прежние настройки. У случайных эффектов кнопка «Другой вариант» меняет seed только по вашему действию.
5. Во вкладке «Цвет» доступны коррекция и RGB-кривые. «Полотно / обрезка» находится также в меню ⋮.
6. Для сравнения удерживайте «Оригинал». Масштабируйте просмотр двумя пальцами и перемещайте изображение; двойное касание возвращает вписывание.
7. Кнопка Undo вверху отменяет последнее подтверждённое изменение. Масштаб просмотра не меняет размер сохраняемого файла.

Редактор принимает sRGB. Для файла с другим цветовым пространством или PNG 16 бит он покажет сообщение с просьбой заранее преобразовать копию в sRGB RGBA8. Скрытого преобразования повышенной битности нет.

## Создать изображение с нуля

На стартовом экране нажмите «Создать полотно». Выберите шаблон 1:1, 4:5, 9:16 или введите ширину и высоту. `#00000000` означает полностью прозрачный фон. Для полотна из задания введите 3000 × 3000.

Во вкладке «Слои» добавьте генератор. Есть градиенты, Perlin, Voronoi, полосы и шахматный узор. Палитра редактируется. Можно добавить текст и рисовать на отдельном прозрачном слое.

## Слои и дерево

- Вкладка «Слои» показывает слои сверху вниз. Выберите строку, чтобы сделать слой активным. Новые эффекты добавляются к активному слою.
- «Правка» открывает имя, непрозрачность, режим смешивания, положение, масштаб, поворот и отражение. Там же находятся «Выше», «Ниже», «Копия», «Удалить» и маска.
- Кнопка «Дерево» находится рядом с названием панели слоёв. Выберите ранее применённый эффект и нажмите «Настроить»: изменения пересчитают следующие узлы.
- Эффект можно отключить без удаления настроек. «Входы узла» позволяют переподключить ветвь; соединение с циклом отклоняется.
- «Смешать ветви» объединяет два входа. Входами могут быть исходники, генераторы, эффекты и маски. Узел маски создаётся через «Маска из ветви» и подключается как «Вход маски» или через «Входы узла».
- Для «Карты смещения» можно выбрать другую ветвь: красный канал задаёт сдвиг X, зелёный — Y. Без внешнего входа используется процедурная карта.

Слои и дерево — два представления одного документа. Перезапуск сохраняет редактируемую структуру.

## Маски

В свойствах слоя или эффекта нажмите кнопку маски. Белое показывает результат, чёрное скрывает. Можно выбрать диапазон яркости или цвета, инвертировать выделение и сбросить маску.

«Применить и рисовать кистью» закрывает окно и открывает кисть под изображением. Ластик скрывает области, обычная кисть восстанавливает их. Размер, мягкость и непрозрачность доступны ползунками и числом. Для жестов просмотра включите «Перемещение»; для продолжения рисования выключите этот режим. «Готово» закрывает кисть. Каждый законченный штрих можно отменить Undo.

## Текст, шрифты и рисунок

Во вкладке «Текст» создайте надпись или редактируйте выбранный текстовый слой. Есть кириллица и латиница, размер, цвет с альфа-каналом, выравнивание, интервалы, обводка и тень. Положение, поворот и масштаб находятся в свойствах слоя.

«Применить и импортировать TTF» открывает системный выбор файла шрифта. Файл копируется внутрь проекта и входит в сохраняемый `.sf7blab`; доступ к исходной папке шрифтов потом не нужен. После импорта шрифт остаётся доступным без интернета.

Во вкладке «Рисование» используется отдельный прозрачный слой. Штрихи сохраняются в виде точек и параметров кисти и заново рассчитываются при экспорте исходного размера.

## Проекты и наборы

Изменения автоматически записываются во внутреннее хранилище после подтверждённых действий. Есть последняя исправная копия манифеста. После обычного закрытия или выгрузки процесса откройте приложение и нажмите «Продолжить».

Для переноса и резервного сохранения выберите ⋮ → «Сохранить проект». Файл `.sf7blab` содержит исходники, слои, граф, маски, штрихи, текст и шрифты. Откройте его через «Открыть проект». Проверка повреждённого файла выполняется до замены текущей работы.

Перед новой работой приложение предлагает сохранить старую в файл и требует явного выбора «Заменить». Удаление приложения средствами Android удаляет внутреннее рабочее хранилище, поэтому перед этим сохраните `.sf7blab` отдельно.

В меню ⋮ → «Наборы настроек» есть восемь авторских вариантов. «Сохранить цепочку» сохраняет эффекты активного слоя с параметрами, масками и seed. Пользовательские наборы можно переименовать, удалить, импортировать и экспортировать. Для разветвлённой композиции с отдельными входами используйте проект: наборы предназначены для линейной цепочки эффектов активного слоя.

## Экспорт PNG

Нажмите кнопку экспорта в верхней панели. По умолчанию сохраняется исходный размер с учётом обрезки и поворота. Можно задать ширину и высоту, сохранить пропорции, оставить прозрачность или выбрать непрозрачный фон. Затем выберите локальную папку в системном окне и нажмите «Сохранить».

Приложение рассчитывает результат из исходников. Шахматная подложка не попадает в PNG. Выход — sRGB RGBA, 8 бит на канал. Промежуточное JPEG-сжатие не применяется. PNG не восстанавливает детали, которые были потеряны в исходном JPEG.

Во время обработки доступна отмена. Сначала создаётся временный полный PNG, затем он переносится в выбранное место. Сообщение об успехе появляется только после завершения записи. Очень большие проекты требуют свободного места для временных файлов. Если ресурсов недостаточно, приложение сообщает об ошибке и не уменьшает размер самостоятельно.

## Бесплатно собрать исходники на этом компьютере

Для пользования готовым APK сборка не нужна. На компьютере владельца уже подготовлены JDK 17, Android SDK 36 и Gradle Wrapper. Дополнительные платные сервисы не используются.

Откройте PowerShell, вставьте обе строки и дождитесь окончания:

```powershell
Set-Location '<repository>'
.\tools\build-local.ps1 -Tests
```

Ожидаемый результат: `BUILD SUCCESSFUL`, затем строка с путём к `artifacts\sf7b-lab-debug.apk`. Первая сборка требует интернета для бесплатных зависимостей. Готовое приложение работает без него.

Скрипт использует отдельную папку вывода `%LOCALAPPDATA%\sf7b-lab-build`: это обходит обнаруженную проблему тестового процесса JDK 17 с кириллицей в пути. Исходники остаются в этой папке проекта.

Для другого компьютера установите бесплатный [Android Studio](https://developer.android.com/studio), JDK 17 и через SDK Manager — Android SDK Platform 36 и Build-Tools 35.0.0. В Android Studio выберите **Open**, укажите папку с `settings.gradle.kts`, дождитесь синхронизации. Сборка: **Build → Build APK(s)**. Не обновляйте закреплённые версии автоматически до проверки совместимости. Проверенная связка описана в [документации AGP 8.13](https://developer.android.com/build/releases/agp-8-13-0-release-notes).

Если на текущем компьютере понадобится восстановить SDK:

```powershell
Set-Location '<repository>'
.\tools\setup-android.ps1
```

## Обновления с сохранением подписи

Ключ хранится вне checkout. Настройте переменные SF7B_KEYSTORE_PATH, SF7B_STORE_PASSWORD, SF7B_KEY_ALIAS и SF7B_KEY_PASSWORD по [SIGNING](docs/SIGNING.md). Для обновления уже установленной версии нужен прежний ключ; обычная debug-сборка нового компьютера может иметь другую подпись. Не удаляйте приложение и не очищайте его данные ради установки.

## Проверки и продолжение

- `TEST_REPORT.md` — что действительно проверено и что требует телефона.
- `EFFECTS_CATALOG.md` — эффекты, параметры и статус сходства.
- `DESIGN.md` — экраны, темы и состояния.
- `STATE.md` — команды, известные ограничения и дальнейшая работа.
- `REFERENCE_REQUEST.md` — единый список образцов для проверки Ilixa.
- `DEPENDENCIES.md` и `licenses` — зависимости и лицензии.

Для подключённого и разблокированного тестового устройства с разрешённой отладкой по USB:

```powershell
Set-Location '<repository>'
.\tools\build-local.ps1 -Tests -DeviceTests
```

Это установит приложение и тестовый пакет, затем выполнит сценарии. Ручной сценарий для A51 приведён в TEST_REPORT.md.
