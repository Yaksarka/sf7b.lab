# Статические схемы и контракты оригиналов — пункт 3.3

Проверены предоставленные One Lab 1.5.3/code138 и Glitch Lab 1.7.4/code999. Это восстановление деклараций и диспетчеризации, без исполнения APK. Пользовательские маршруты, фактическая видимость, поведение и паритет относятся к следующим пунктам.

Машиночитаемые данные: SCHEMA_COVERAGE.json (материал отсутствует в этой копии), контракты (материал отсутствует в этой копии). Предыдущий coverage сохранён побайтно в SCHEMA_COVERAGE_BEFORE_TASK3_3.json (материал отсутствует в этой копии). Проверки и хеши: [отчёт](../docs/verification/reference-task3.3-20261114.md).

## One Lab

Восстановлены 214 прототипов T5.x2; просмотрены 858 class profiles, включая источники m6.o2 и алиасы m6.T0. У 531 профиля восстановлены списки параметров: 5032 позиции. Это позиции с повторениями между классами, а не число уникальных настроек. Есть 592 различных binding records / 581 operator ID; 576 ID участвуют в базе разрешения DSL-наследования. Разные числа отражают разные множества.

135 заголовков DSL содержат 519 параметров: 131 именованный заголовок и четыре анонимных. Все 414 прежде неразрешённых цепочек наследования восстановлены; ошибки разбора и неоднозначные наследуемые параметры отсутствуют. Три строки-фрагмента учтены отдельно: части конкатенации не считаются самостоятельными схемами, identity lambda не объявляет metadata. Dossier восстановлен из конкатенации; значение палитры остаётся динамическим.

Сохраняются тип, default, другие defaults, standard/definition/ideal ranges, choices, tags, priority, hidden/requires, manipulator/transform metadata, sliderScale и привязки входов. В восстановленных native default/range expressions нет неразрешённых символов. Обязательные параметры обобщённых конструкторов помечены constructor-dependent. Число и физическая единица не угадываются по имени, иконке или диапазону; не объявленные явно единицы отмечены отдельно.

| Контракт | Восстановленное правило |
|---|---|
| `p2.r(a,b)` | Случайный default, а не границы слайдера. |
| `p2.X`, `p2.s`, `p2.D` | Соответственно standardRange, definitionRange, idealRange. |
| Копирование p2 | Два bitmask; не переопределённые поля наследуются. |
| Обёртки a.a.o/p | Заменяемый вход удаляется, если его имя отличается от `source`; `source` сохраняется. Дополнительный параметр вставляется в заданную позицию. |
| Матрицы | Сохранены фабрики, порядок произведений и inverse, float32; они не заменяются матрицей предпросмотра. |
| V5.s | GPULoad(mainLoad, sourceMultipliers), не аппаратный gate и не измеренное время. |
| Источники m6.o2 | Discriminant 0 вызывает load-image, другая ветвь load-video. Это маршруты выбора источника, не два алгоритма изображения. |
| m6.T0 | Ссылка на базовый maker и именованный вариант; отдельным алгоритмом не считается. |

Лицензионный enum: V=Dev, W=Free, X=Plus, Y=Pro, Z=Max, a0=Test, b0=Alpha, c0=Beta, d0=Any. M0 wrappers и license codes сохранены на каждой registration. Доступа One PRO нет; статическая схема закрытой функции не подтверждает её доступность на телефоне.

Два synthetic helper (`alchemy.c`, `perspective.a`) имеют пустой standalone JADX output; они не зарегистрированы выбранными корнями и не считаются потерянными эффектами. Их DEX metadata, export status и классификация сохранены. Отсутствующий ошибочно запрошенный `a.o` отмечен в supplemental export; действительный predicate — A7.o. Профили без собственного списка параметров включают DSL makers, aliases, вспомогательные и абстрактные типы; им не приписываются выдуманные параметры.

## Glitch Lab

Извлечены 175 selector call sites / 174 ID; два варианта `locus_mode_with_cd` сохранены раздельно. Просмотрены 413 class candidates, включая группы и helpers: у 380 восстановлен непосредственный начальный граф, у VignetteShapeGL — условные варианты. Дополнительно восстановлены все 120 inline graphs FragmentGlitch.initGlitchTypes. Это не число видимых эффектов.

Сохранены 2239 привязок параметров class profiles и шесть строковых functional-group привязок inline registrations. Legacy View arguments также сохранены; шесть — не число всех их кнопок. Например, для genericIteration10000Button в сохранённых DEX references есть чтение в initGlitchTypes, прямой записи не найдено. Такие старые View-ссылки не объявляются действующими настройками. Runtime должен установить, какие маршруты доступны.

| Контракт | Восстановленное правило |
|---|---|
| Float selector | size/scaleInDp отделён от min/max; сохраняются intMode, intModeMultiple, logMode и proMode. |
| Radians selector | Хранит радианы, показывает градусы; обратное преобразование ×PI/180. |
| Degrees selector | Хранит градусы. stickyPeriod и scaleInDp не являются default. |
| Item selector | Сохраняются варианты, provider и gate. Набор, создаваемый провайдером, не объявляется фиксированным списком чисел. |
| applySetRefAction | model reference направляется на именованный узел графа. FilterRef пересылает setArg этому узлу. |
| Условный makeBlur | Сохранены обе ветви GL/RenderScript; платформа A51 не выбиралась предположением. |
| Factory unset | Если arg не задан, syncSelectorToFilter не меняет selection без Constant. Midpoint диапазона не считается начальным значением. |

Для class profiles сохранены 1900 factory values, 377 not-set-by-factory, 30 contextual-input, один constructor-dependent и три runtime-resource-key. Это записи с повторами/альтернативными ветвями. Незаданный arg и контекстный ресурс не являются доказанным числовым default. Привязки без явного applySetRefAction отмечены root-candidate, а не подтверждённым UI route.

Контрольный Bloom: граф явно создаёт intensity=20, darken.hardness=50 и blur.blur=10; normalize/gamma=0. Эти значения не переносятся автоматически на одноимённые аргументы других узлов или шкалу One Lab.

Различаются effect setPro, selector proMode, item requiresPro и условия hasFull/hasDev/hasPresetPack/useBetaFilters. Ни один gate не обходился. Предоставленный Glitch остаётся mod без подтверждённого официального контроля.

## Граница результата

Все 961 позиции реестра 3.2 сохранены, включая пустые/условные позиции, wrappers и варианты. Полные оригинальные Java, REA Evidence и промежуточные выражения находятся вне Android source в `.sf7b-private-reference-audits/20261114-task3.3`. В собственный APK/архив их включать нельзя. В coverage перенесены metadata и ссылки, тела алгоритмов исключены.

One supplied/installed имеют одинаковый DEX, но разные ресурсы. Runtime/UI/resource equivalence не установлена. Следующий пункт 3.4 требует отдельных опытов на собственных fixtures; здесь он не выполнялся.
