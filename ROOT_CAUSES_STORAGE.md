# Причины дефектов хранения и инструментов

Установлено чтением исходников 13.11.2026; пользовательские случаи необходимо проверять на установленном приложении отдельно.

| Симптом | Установленный участок и исправление |
| --- | --- |
| Новая работа заменяет предыдущую; нет независимой галереи | Старый EditorModel использовал единственную filesDir/workspace. Добавлена библиотека UUID-папок, отдельный индекс и ресурсы каждой работы; root интегрирует переключение с ожиданием записей. |
| Нельзя безопасно удалить/изменить копию | Не было операции копии самостоятельного проекта. ProjectLibrary.duplicate копирует граф, seed и все ресурсы в новый UUID. |
| Риск повреждения резервной JSON-копии при обрыве записи | Старый save обновлял last-good обычным Files.copy прямо в конечный файл. Теперь и документ, и backup публикуются из сброшенных на диск приватных временных файлов. |
| Архив может содержать изменённые, но структурно допустимые ресурсы | Старый .sf7blab не имел контрольных сумм. Добавлен версионированный package.json с размером/SHA-256 всех членов; legacy v1 остаётся читаемым. |
| Ошибка распаковки оставляет частично извлечённые ресурсы | Старый unpack писал прямо в переданную папку. Теперь нужна пустая цель, извлечение/проверка выполняются в приватной staging-папке; до проверки текущий проект не затрагивается. |
| Потеря библиотеки при повреждении индекса | Раньше самостоятельного индекса не было. Теперь есть atomic JSON + backup, метаданные каждой UUID-папки и восстановление опубликованных папок. |
| Поздний рендер может обновить неверную миниатюру | ProjectLibrary.saveThumbnail сравнивает ожидаемый документ; удалённые ID и устаревшие ревизии не публикуются. Привязка рендера/записей к ID выполняется EditorModel. |
| Выбранная пропорция crop нарушается после 90° | CropPanel вычислял отношение по исходной ширине/высоте, игнорируя frame.turn. Теперь учитывается отношение итогового файла; изменение ширины/высоты сохраняет выбранную пропорцию. |
| Числовой ввод неудобен и преждевременно показывает ошибку на «-» | NumberControl использовал текстовую клавиатуру и сразу помечал промежуточное состояние ошибкой. Добавлены decimal/Done, разбор запятой, сохранение промежуточных значений без применения. |
| Для выбора цвета требуется знать hex | В ColorControl были hex и несколько образцов. Добавлены отдельные RGB/alpha ползунки; hex сохраняется для точного ввода. |
| Размер экспорта мог остаться от другой работы | ExportPanel remember не был привязан к проекту/размерам. Добавлены соответствующие ключи. |
| Названия генераторов переводились на русский | LayersPanel выбирал def.ru. Теперь имена генераторов отображаются на английском, локализация параметров сохраняется. |

Исходники не доказывают причину каждого сообщения пользователя. В частности, пропажу конкретной ранее утраченной работы или изменение seed после перезапуска нельзя объявлять воспроизведёнными без исходного файла/сценария. Новые контракты сериализации и copy проверяют эти инварианты для контролируемых данных. Корректность цветов/рендера исследуется отдельно в ROOT_CAUSES_RENDER.md.
